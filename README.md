# bevasarlo-akcio-adat

Bevásárló app – Akcióvadászat: nyilvános adat (kapcsoló, akciós ajánlatok). Csak adat, kód nincs benne.

- Ide csak az újságolvasó robot ír (a `bevasarlo-akciok` tárolóból, egy csak erre a tárolóra szóló kulccsal).
- A telefon innen olvassa: `kapcsolo.json`, `akciok/index.json`, `akciok/ujsag/*.json` (a forma: APP.md 2026.11.12. 15:14, 2. pont).
- Döntés: DONTESEK.md, 2026.11.12. 15:20.
